# 촉한전기 업데이트

촉한전기 PC판의 작은 파일 패치 전용 공개 저장소입니다.

현재 배포 버전: **0.39.6** (2026-10-11)

- 2막 7~13장 적 병력 10% 감소. 일반병·정예병·적장·증원 모두 적용.
- 공격력·방어력·정예 편성과 1막·3막은 유지.
- 진행 중 저장은 기존 전투 상태를 유지하며, 재도전·다음 출전부터 새 병력 적용.
- 새 게임을 시작할 필요는 없습니다.

업데이트 주소: https://raw.githubusercontent.com/syrano15/shu-tactics-updates/main/updates/latest.json

기존 0.39.5판은 타이틀의 배포 주소 설정에 위 주소를 처음 한 번 입력한 뒤 업데이트 확인·적용을 누르세요. 0.39.6부터 주소를 설정하지 않은 새 사용자에게 이 주소를 자동으로 연결합니다. 기존에 지정한 다른 주소는 보존합니다.

일반 업데이트는 변경된 파일만 내려받습니다. 적용은 타이틀에서 사용자가 버튼을 눌러 실행합니다. 업데이트 과정에서 개인 저장 데이터는 바꾸지 않습니다.

`updates/latest.json`은 전체 활성 파일 목록이며 `updates/files`의 파일 이름은 SHA256입니다. 기존 파일 객체를 삭제하지 않아 이전 버전 사용자도 업데이트할 수 있게 유지합니다.
