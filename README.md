# 촉한전기

현재 버전: **v0.72.0** · 1~7막, 1~56장 완결

[웹에서 실행](https://syrano15.github.io/shu-tactics-updates/)

통합 실행 기획서 v5.1에 따라 전투 화면과 출전 준비 화면을 정리합니다. 제목은 실제 막·장·이름을 표시하고, 상시 단계·조건·장수 목록·조작 안내를 접어 전장 공간을 넓힙니다. 평상시 빈 땅 메뉴의 전투 목표에서 기존 승패·보호·출구 조건을 확인할 수 있습니다. 턴 종료는 기본 좌하단, 선택 장수 명령은 우하단 문맥 영역에 둡니다.
행동 완료 유닛은 실제 행동 상태에 따라 회색으로 표시합니다. 강의 연결 수면·해안·모서리·기존 다리 표현을 정리하고, 강하 피난선의 기존 R6 좌표를 유지한 채 목조 접안판과 그림 기준점을 맞춥니다. 이동·통행·나루 도달·3라운드·피난선 보호 조건은 바꾸지 않습니다.
강화·판매·장비·병과·선택 정신기의 실제 데이터를 같은 반응형 흐름으로 정리하고, 정신기 8종과 대표 공격의 표시·효과 구별을 보강합니다. PC와 휴대전화 크롬은 같은 기능·데이터·명령을 사용하며 배치만 조정합니다. 지도 끌기와 대상 지정의 입력 우선순위, 좁은 화면의 문맥 가림과 조작 크기를 정리합니다.
1~7막 56장·Lv99와 기존 육성·장비·자금·진행·완료·보상·저장 형식을 보존합니다. 치명타 토글과 상태 문구를 화면에서 걷어내되 치명타 계산과 저장된 선호는 유지합니다. 적 정신기·SP·AI·HP·밸런스·대사·승인 초상은 변경하지 않습니다.
독립 저작/제조 자료의 자동·정적 검사와 실제 사용자 플레이를 구분합니다. 이번 작업에서 실제 브라우저 플레이·PC/휴대전화 사용감·최종 미술 승인은 완료로 주장하지 않습니다. 개인 저장·인증정보·검수 프로필·원천 아트·개발용 생성 프롬프트는 공개하지 않습니다. 수동 패치는 기존 96MiB 안전한도를 유지하고, 초과 시 생성하지 않으며 전체 PC 실행본과 온라인 개별 파일 갱신을 제공합니다.

기존 장별 완료와 육성은 보존합니다. 다른 진행을 합치지 않으며 클라우드 충돌에서는 양쪽 원본을 보관하고 선택합니다. 현재 진행만 연동하고 수동 저장 56칸·장 시작·클리어·완료 기록은 각 기기에 남습니다.

updates/latest.json은 검증된 전체 실행 파일 목록이며 updates/files는 SHA-256 이름의 내용입니다. 새 버전에서 필요한 파일만 추가하며 이전 공개 파일은 삭제하거나 덮어쓰지 않습니다. 개인 저장·인증정보·검수 프로필·개발용 프롬프트·원천 아트는 게시하지 않습니다.
