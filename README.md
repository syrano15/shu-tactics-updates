# 촉한전기 업데이트

현재 버전: **v0.50.0**

기존 PC 타이틀에서 업데이트 확인 → 업데이트 적용 → 이어 하기를 사용합니다. 기존 2막 저장과 개인 성장·장비·진행·완료 보상을 보존합니다.

- 5막 형주 결전 32~37장: 번성 포위, 칠군 수몰, 서황의 원군, 백의도강, 맥성, 강릉 탈환을 추가했습니다.
- 맥성에서 관우가 살아 돌아오는 분기와 37장 정규16명 편성을 연결했습니다. 기존 31장 완료 저장은 마지막 정비에서 32장으로 이어집니다.
- 5막 지원·거점 EXP, 저성장 최대6명/3승 지원과 첫 승리 군수금20,000·선택거점3,000을 독립 기록으로 관리합니다. 과거 막 보상을 다시 지급하지 않습니다.
- 빠진 이름 있는 장수17명의 고유 초상과 5막 지도7개를 제작했습니다. 미래 장수9명은 그림을 준비하고 기존 합류 시점을 유지합니다.
- Lv99 성장·Lv30 선택 정신기·Lv50 고유 필살기·강화15·MAX특성과 기존1~4막 전투 규칙을 유지합니다. 옛45/60 성장 기록·부상·SP·투자·진행·정산을 보존합니다.
- 현재 1~5막 1~37장입니다. 6막 이후는 아직 미구현입니다.

v0.40.1의 자연 병력 합산·이동 후 군량·2막 증원 완화·관우5턴 안내·지도 개선·천리행 수레 동행을 유지합니다.

검수는 제조 저장, 실제 엔진 API, 화면 확인과 격리 PC 실행을 구분합니다. 인간 전체 캠페인 완주나 모든 편성의 장기 난도를 보장하는 결과는 아닙니다.

`updates/latest.json`은 전체 실행 자료 목록이며 `updates/files/`는 SHA256 이름의 자료입니다. 크기·해시·호환성을 검증하고 변경된 파일만 내려받습니다. 이전 공개 자료는 보존하며 개인 저장·검수 프로필·개발 문서·원천 아트는 게시하지 않습니다.
