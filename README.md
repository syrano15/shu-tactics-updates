# 촉한전기 업데이트

촉한전기 PC판의 작은 파일 패치 전용 공개 저장소입니다.

현재 배포 버전: **0.39.7** (2026-10-12)

- 2막 7~13장 적 정예→강화, 강화→일반으로 한 단계 하향.
- HP와 실제 공격·방어·승급 능력, 대기 증원까지 함께 조정.
- 기존 2막 저장도 이어하기·불러오기 즉시 적용. 새 게임·재도전 불필요.
- 아군 성장·장비·진행·자금·보상 유지. 1막·3막 유지.

타이틀에서 **업데이트 확인 → v0.39.7 적용 → 이어하기**를 누르세요.

업데이트 주소: https://raw.githubusercontent.com/syrano15/shu-tactics-updates/main/updates/latest.json

기존 0.39.5판은 타이틀의 배포 주소 설정에 위 주소를 처음 한 번 입력한 뒤 업데이트 확인·적용을 누르세요. 0.39.6부터 주소를 설정하지 않은 사용자에게 자동 연결됩니다. 기존에 지정한 다른 주소는 보존합니다.

업데이트는 변경된 파일만 내려받고, 적용은 사용자가 버튼을 눌러 실행합니다. 개인 저장을 삭제하지 않습니다. 저장된 진행 중 2막 전투를 불러올 때 새 밸런스를 자동 적용합니다. 완료한 전투의 정산 기록은 그대로 유지합니다.

`updates/latest.json`은 전체 활성 파일 목록이며 `updates/files`의 파일 이름은 SHA256입니다. 이전 파일 객체를 보존하여 구버전 사용자도 업데이트할 수 있게 유지합니다.
