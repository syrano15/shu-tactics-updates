# 촉한전기 업데이트

현재 버전: **v0.39.8**

타이틀의 업데이트 확인 → 업데이트 적용 → 이어하기를 사용합니다. 기존 2막 저장에 적용되며 새 게임을 시작할 필요가 없습니다. 이미 정산한 완료 기록은 유지합니다.

- 기존 고유 필살기 6종 지도 이펙트, 범위 공격 동시 피격 표시.
- 필살기 1턴 휴식·진행 저장 대기 시간 단축, 정신기 대사 0.9초.
- 적장 격파 시 해당 적군 행동 한 차례 확정 혼란, 기존 상태 보존.
- 책사·미축 보급의 다른 아군 SP+15, 간옹 군심 수습 SP+20.
- 2막 정예·강화 복구, v0.39.7의 낮은 HP 유지. 사기 공격 효과 강화.
- 하비 강 우회로 수정·일반 적 2부대 추가·새 지도.

일반 패치는 변경된 파일만 내려받습니다. 게임 코드와 표시용 지도만 공개하며 개인 저장이나 비공개 원본 저장소는 포함하지 않습니다. 파일 크기와 SHA256을 검증하고 같은 게임 저장 폴더를 유지합니다.

배포 목록은 `updates/latest.json`, 실제 파일은 `updates/files/`의 해시 이름으로 제공합니다. 이전 파일은 구 PC 패치 호환을 위해 보존합니다. 승급별 추가 필살기는 별도 기획 단계이며 이 배포에 새 기술을 대량 추가하지 않았습니다.
