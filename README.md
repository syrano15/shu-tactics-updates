[웹에서 실행](https://syrano15.github.io/shu-tactics-updates/)

장수 그림 방향을 점검하고 낙봉파 새 전투의 적 배치·협곡 지도·타일을 포위 탈출전에 맞게 개선합니다. 기존 저장과 다른55장 진행을 보존하며 영구 삭제는 추가하지 않습니다.

전체 장수 그림의 방향을 점검하고24장 낙봉파 새 전투를 적의 포위에서 빠져나가는 협곡 전장으로 개선합니다. 기존 지도 배치0/1 저장과 다른55장, 원본 시나리오·그림은 보존하며 장수의 영구 삭제를 추가하지 않습니다.

updates/latest.json은 전체 실행 파일 명세이고 updates/files는 내용의 SHA-256 이름입니다. 기존 공개 객체와 Git 트리는 보존하고 새 객체만 추가합니다. 개인 저장·인증·프로필·개인 QA·프롬프트 원문은 게시하지 않습니다.
