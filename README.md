# 촉한전기

현재 버전: **v0.72.5** · 1~7막, 1~56장 완결

[웹에서 실행](https://syrano15.github.io/shu-tactics-updates/)

제공해 주신 음원으로 전투 종료·턴 시작·회피·검/창 공격·치명타 소리를 교체했습니다. 필중·기합·집중·가속·철벽은 각각 다른 소리로, 필살기는 별도 발동 음성으로 연결했습니다. 전투와 패배 BGM을 스트리밍으로 재생하고 설정의 음량에서 효과음과 배경음악을 따로 조절합니다. 기존 저장·육성·전투 판정과 v0.72.4 수정 사항을 보존합니다.

기존 장별 완료와 육성은 보존합니다. 다른 진행을 합치지 않으며 클라우드 충돌에서는 양쪽 원본을 보관하고 선택합니다. 현재 진행만 연동하고 수동 저장 56칸·장 시작·클리어·완료 기록은 각 기기에 남습니다.

updates/latest.json은 검증된 전체 실행 파일 목록이며 updates/files는 SHA-256 이름의 내용입니다. 새 버전에서 필요한 파일만 추가하며 이전 공개 파일은 삭제하거나 덮어쓰지 않습니다. 개인 저장·인증정보·검수 프로필·개발용 프롬프트·원천 아트는 게시하지 않습니다.
