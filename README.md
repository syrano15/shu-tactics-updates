v0.70.0 · 7막 북벌과 촉한전기 완결

천수부터 장안까지 46~56장, 강유·고상 합류, 기곡 수레 수동 호위·칠성등 방어·위수 도하·장안 결전과 엔딩을 추가했습니다. 7막 성장 지원과 첫 승리 군수 정산, 완료 기록·엔딩 다시 보기·재도전을 연결합니다. 기존 1~6막 진행·Lv99·육성·장비·완료 보상과 저장 형식2·실행기 ABI1을 보존합니다.

PC 클라우드는 v0.61.2 이후 새 전체 실행본이 필요합니다. 로그인과 현재 진행 연동은 기존 설정을 유지하며 수동 저장·장별 기록은 각 기기에 보관합니다. 새 전체 PC 실행본을 함께 제공합니다. 수동 패치가 96 MiB 한도를 초과하면 수동 패치 파일은 제공하지 않고, 안전 한도와 이전 공개 자료를 그대로 유지합니다.

기존 장별 완료와 육성은 보존합니다. 다른 진행을 합치지 않으며 클라우드 충돌에서는 양쪽 원본을 보관하고 선택합니다. 현재 진행만 연동하고 수동 저장 56칸·장 시작·클리어·완료 기록은 각 기기에 남습니다.

updates/latest.json은 검증된 전체 실행 파일 목록이며 updates/files는 SHA-256 이름의 내용입니다. 새 버전에서 필요한 파일만 추가하며 이전 공개 파일은 삭제하거나 덮어쓰지 않습니다. 개인 저장·인증정보·검수 프로필·개발용 프롬프트·원천 아트는 게시하지 않습니다.
