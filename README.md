# 촉한전기

현재 버전: **v0.61.2** · 본편 1~6막 45장 · Lv99

## 클라우드로 현재 진행 이어 하기

새 PC 전체본과 웹 게임의 **클라우드 저장**에서 같은 게임 계정으로 로그인합니다.

1. 집 PC에서 현재 진행을 클라우드에 업로드합니다.
2. 회사 웹에서 로그인하고 현재 진행을 비교합니다.
3. 두 진행이 다르면 양쪽 원본을 먼저 보관한 뒤 **클라우드 진행 사용**을 선택해 이어 갑니다. 로그인만으로 진행을 덮어쓰지 않습니다.

클라우드에는 현재 진행 하나만 보관합니다. 수동 저장 56칸과 장별 클리어 기록은 각 기기에 남습니다. 연결이 없거나 저장에 실패해도 로컬 게임과 저장을 계속 사용할 수 있으며, JSON 내보내기/가져오기도 유지합니다.

기본 로그인은 앱을 종료하면 풀립니다. **로그인 유지**는 직접 선택합니다.

## PC 업데이트

PC 클라우드를 사용하려면 **새 PC 전체본**이 필요합니다. 기존 실행기에 타이틀의 게임 업데이트만 적용하면 로컬 게임과 저장은 계속 사용할 수 있지만, 클라우드 기능은 추가되지 않습니다. 기존 육성·장비·강화·자금·진행을 보존합니다.

이번 버전은 PC에서 정상 로그인이 거부되던 문제를 고쳤습니다.

## 웹 실행과 저장

웹 게임: https://syrano15.github.io/shu-tactics-updates/

같은 주소를 회사·노트북의 브라우저에서 열 수 있습니다. GitHub Actions가 검증한 최신 게임 실행 자료만 웹으로 게시합니다. 웹의 로컬 저장은 기기·브라우저·주소별로 보관합니다.

2막 적 증원은 전장마다 최대 한 번이며 천리행에는 없습니다. 주창의 아군 합류와 수레 직접 조작을 유지합니다. 전용 저장 공간, 반복 혼란/위보 보호, 기존 저장의 이미 등장한 적과 완료 기록도 유지합니다. 7막 전투는 아직 미구현입니다.

개인 저장 원문·프로필·개발 문서·검수 자료·원천 아트·인증정보는 이 공개 저장소에 포함하지 않습니다.
