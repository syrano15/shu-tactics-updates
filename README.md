# 촉한전기 업데이트

현재 버전: **v0.40.0**

기존 PC의 타이틀에서 업데이트 확인 → 업데이트 적용 → 이어 하기를 사용합니다. 기존 2막 저장으로 계속 진행할 수 있으며 새 게임을 시작할 필요가 없습니다. 이미 정산한 보상과 성장·장비·진행 기록을 보존합니다.

- 4막 22장 가맹관부터 31장 한중왕까지 10개 전장. 정규 출전 12→14명.
- 신규 인물 15명의 개별 초상, 전장별 새 지도와 4막 여정 지도, 간결한 대사.
- 다전선 거점·후방 구출·산악전·성문 점령·하천 돌파. 전장별 고정 적 전력.
- 실제 회복·SP 보급·지원 효과·거점 기여 경험치. 저성장 6명까지 처음 승리 출전 3회 지원·거점 경험치 1.5배 선택.
- 새 합류 장수만 현재 군단을 기준으로 성장 보정. 각 장 첫 승리 군수금 20,000골, 선택 보급금 3,000골.
- 3막 완료 저장도 기존 정비에서 4막으로 이어집니다. 5~6막은 이번 배포에 포함되지 않습니다.

패치는 변경된 파일만 내려받고 파일 크기·SHA256을 검증합니다. 같은 PC 저장 폴더를 유지하며 이전 버전 파일은 호환을 위해 보존합니다. 공개 배포에는 게임 실행 파일 목록과 표시 자산만 포함하며 개인 저장·검수 프로필·비공개 개발 자료는 포함하지 않습니다.

배포 목록은 `updates/latest.json`, 실제 파일은 `updates/files/`의 해시 이름입니다. 4막 밸런스는 여러 편성의 실제 엔진 자동전투로 확인했으며 사람의 전체 캠페인 완주나 모든 편성의 난도를 보장하는 기록과는 구분합니다.
