# 촉한전기 업데이트

현재 버전: **v0.40.1**

기존 PC 타이틀에서 업데이트 확인 → 업데이트 적용 → 이어 하기를 사용합니다. 기존 2막 저장을 이어갈 수 있으며 새 게임을 시작할 필요가 없습니다. 개인 저장과 성장·장비·완료 보상을 보존합니다.

- 아군 공통 병력 10,000 제한 해제. 장수·병과·성장·강화·장비·고유 특성 합산, 강화15단계 유지.
- Lv30 정비에서 네 번째 정신기 무료 선택·교체, 기본3개와 합쳐 최대4개. 선택 가능 장수 알림.
- 정규37명 전체MAX 고유특성, Lv50 고유필살기. 고유기 전투당1회, 일반 필살기 사용 후 두 턴 휴식.
- 이동 후 군량, 비책사 일반 보/창/활/석궁 이동 개선과 전문화 최소3. 책사 기본 이동 유지, 적 책사HP20%하향.
- 2막 증원파동 최대4명, 소패 관우5턴 시작 이탈 안내, 범위 필살기 지도 연출.
- 하비·백마·천리행·신야·장판 지도와 다리 개선, 천리행 수레 안전 자동 동행.

활성 구 저장은 아군 최대 병력 증가분을 한 번 반영하여 받은 피해를 보존합니다. 퇴각 부대·사망 적·이미 등장한 증원·확보한 승리 기준·완료 기록은 유지합니다. 네 번째 정신기는 정비에서 직접 선택하고 기존 수레는 수동 상태로 시작합니다.

4막22~31장은 유지됩니다. 5~6막과 최종15~18명 출전은 아직 미래 계획입니다. 검수는 제조 저장과 실제 엔진 자동 명령·격리 PC 실행으로 수행했으며 인간 전체 완주나 모든 편성의 난도 보장을 뜻하지 않습니다.

`updates/latest.json`이 전체 실행 파일 목록이며 `updates/files/`는 SHA256 이름의 자료입니다. 크기·해시·호환성을 검증하고 변경된 파일만 내려받습니다. 이전 버전 자료는 보존합니다. 개인 저장·검수 프로필·개발 소스·원천 아트는 이 공개 저장소에 포함하지 않습니다.
