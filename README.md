# 촉한전기 업데이트

현재 버전: **v0.60.1**

기존 PC 타이틀에서 업데이트 확인 → 업데이트 적용 → 이어 하기를 사용합니다. 현재 1~6막 1~45장, Lv99 성장입니다.

- 백마의 일격의 새 전투는 문추 증원 1회만 남겼습니다. 기존 전투는 이미 등장한 적과 전투 기록을 보존하고, 아직 등장하지 않은 추가 일반병 증원만 취소합니다.
- 적 책사의 혼란·위보를 받은 아군에게 재시전 보호를 적용해, 상태가 풀린 직후 또 제어되어 행동 기회를 계속 잃는 상황을 막습니다. 여러 적 책사의 교대 시전에도 같은 보호가 적용됩니다.
- 백마의 나무 판자 다리를 이어진 흙 둑길로 표시합니다. 기존 통행 좌표와 강 지형 판정은 보존합니다.
- 기존 저장의 육성·장비·자금·진행·완료 보상을 보존합니다. 이어하기는 최신 저장의 진행 단계에서 재개합니다.

v0.60.0의 6막 전투와 정규 장수 7명 합류·최종 18명 편성·개인 초상 6명·지도 9개, 기존 1~5막과 Lv30 선택 정신기·Lv50 고유 필살기·강화15를 유지합니다. 7막 이후 전투는 아직 미구현입니다.

검수는 저장 사본, 실제 엔진 API, 화면 확인과 격리 PC 실행을 구분합니다. 개인 저장 원문·검수 프로필·개발 문서·원천 아트·인증정보는 공개하지 않습니다.

`updates/latest.json`의 실행 자료는 크기·해시·호환성을 검증하고 변경 파일만 내려받습니다. 이전 공개 자료와 실행기의 보호 검증을 보존합니다.
