# 촉한전기

현재 버전: **v0.60.3** · 본편 1~6막 45장 · Lv99

## 이번 수정

- 2막 적 증원은 전장마다 최대 한 번입니다. 천리행에는 적 증원이 없습니다. 주창의 원래 아군 합류는 유지합니다.
- 천리행 수레를 직접 선택해 이동·대기합니다. 자동 이동·자동 대기를 제거했고, 수레 행동이 남아 있으면 아군 턴이 자동으로 끝나지 않습니다.
- 기존 저장의 육성·장비·강화·자금·진행과 이미 등장한 적을 보존합니다. 구 활성 전투의 추가 미등장 파동만 취소합니다. 완료 기록은 그대로 유지합니다.

## PC 업데이트

타이틀에서 업데이트 확인 → 업데이트 적용 → 이어 하기를 사용합니다. 같은 PC 실행기·저장 위치를 사용합니다. 이전 공개 자료와 실행기의 크기·해시·호환성 검증을 유지합니다.

## 웹 실행과 저장

웹 게임: https://syrano15.github.io/shu-tactics-updates/

같은 주소를 회사·노트북의 브라우저에서 열 수 있습니다. GitHub Actions가 검증한 최신 실행 자료만 웹으로 게시합니다. 클라우드 연동은 별도 준비 중입니다. 현재 PC와 웹 저장은 기기·주소별로 보관하며, JSON 내보내기/가져오기로 옮길 수 있습니다.

개인 저장 원문·프로필·개발 문서·검수 자료·원천 아트·인증정보는 이 공개 저장소에 포함하지 않습니다.
