# 촉한전기

현재 버전: **v0.72.2** · 1~7막, 1~56장 완결

[웹에서 실행](https://syrano15.github.io/shu-tactics-updates/)

전반 이미지 자료를 전수 검사하고 승인 원화·해상도·RGBA 픽셀·투명도를 유지하는 표시용 무손실 이미지를 추가합니다. 이미지 동시 요청·해독을 작은 공통 대기열로 묶고 현재 화면에 필요한 자료를 우선 준비합니다. 원본·지형·좌표·통행·목표 조건은 보존합니다.
효과음 준비도 최대 2개의 공통 작업과 제한된 캐시를 사용합니다. 실제 재생 요청은 대기 중 장면 준비보다 먼저 처리하고 기존 발동·접촉 시점·120ms 만료·취소·음소거·음량 선호를 유지합니다. 음원과 기존 효과는 바꾸지 않습니다.
새 이미지·효과·음원을 추가할 때 파일 크기·해상도·길이·활성 등록·지역 경로를 확인하는 예산 검사를 제공합니다. 현재 원본의 바이트는 보존하며 향후 새 자료의 준비·취소·메모리 소유권을 문서화합니다.
전 장의 개인 정신기 보유 게스트에게 기존 개인 명령을 연결하고, 이전 군단 기록이 있으면 레벨·병과·승급·강화·장비·선택 정신기를 계승합니다. 이야기의 합류 ID·배치·보호 조건과 임시 합류의 경험치·보상 구분은 유지합니다. 개인 정신기 데이터가 없는 협력부대와 호위물에 새 정신기를 만들지 않습니다.
제갈량 전용으로 최대 병력+1,200·방어+8·지력+10, 화공 위력1.10→1.20·범위 추가1.15→1.20을 적용합니다. 기존 저장은 이전 규칙으로 먼저 검증하고 진행 중인 대상만 한 번 갱신합니다. 생존 병력 비율·퇴각0·SP 소비·좌표·행동·상태·RNG와 완료된 전투 결과는 유지합니다.
1~7막 56장·Lv99, 기존 육성 기록·장비·자금·진행·완료·보상·저장 형식과 치명타 계산·저장된 선호를 보존합니다. 적 정신기·SP·AI·HP·밸런스·대사·승인 초상은 변경하지 않습니다. PC와 휴대전화는 같은 웹 게임의 기능·데이터·명령을 사용합니다.
개인 저장·인증정보·검수 프로필·원천 아트·개발용 생성 프롬프트는 공개하지 않습니다. 자동/정적 검사와 실제 사용자 플레이·체감·최종 미술 승인은 구분합니다. 수동 패치는 기존 96MiB 안전한도를 유지하며 초과하면 생성하지 않고 전체 PC 실행본과 온라인 개별 파일 갱신을 제공합니다.

기존 장별 완료와 육성은 보존합니다. 다른 진행을 합치지 않으며 클라우드 충돌에서는 양쪽 원본을 보관하고 선택합니다. 현재 진행만 연동하고 수동 저장 56칸·장 시작·클리어·완료 기록은 각 기기에 남습니다.

updates/latest.json은 검증된 전체 실행 파일 목록이며 updates/files는 SHA-256 이름의 내용입니다. 새 버전에서 필요한 파일만 추가하며 이전 공개 파일은 삭제하거나 덮어쓰지 않습니다. 개인 저장·인증정보·검수 프로필·개발용 프롬프트·원천 아트는 게시하지 않습니다.
