# 촉한전기

현재 버전: **v0.74.8** · 1~7막, 1~56장 완결

[웹에서 실행](https://syrano15.github.io/shu-tactics-updates/)

현재 진행 비교가 전송 대기를 바꾸지 않도록 수정하고, 이어하기에서 기기와 클라우드 진행을 명시적으로 확인하도록 개선합니다. 클라우드는 현재 진행 1개를 연동하며 수동 슬롯은 각 기기에 보관됩니다. 실제 검증·게시 결과는 이번 출고 영수증으로 확인합니다.

클라우드는 현재 진행 1개를 연동합니다. 수동 슬롯과 장별 보관 기록은 각 기기에 남습니다. 서로 다른 진행은 원본을 보관한 뒤 사용할 진행을 명시적으로 선택합니다.

updates/latest.json은 전체 실행 파일 명세이고 updates/files는 내용의 SHA-256 이름입니다. 기존 공개 객체와 Git 트리는 보존하고 새 객체만 추가합니다. 개인 저장·인증·프로필·개인 QA·프롬프트 원문은 게시하지 않습니다.
