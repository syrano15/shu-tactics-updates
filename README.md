[웹에서 실행](https://syrano15.github.io/shu-tactics-updates/)

병력·장군의 이동 모션, 정상 다리 접안부 지면 표시, 확인된 병력 그림 방향을 개선합니다.

이번 변경은 이동 연출·다리 접안부 지면·병력 그림 방향을 다루며 실제 이동·피해·행동 횟수·지형·저장·보상 규칙은 유지합니다.

updates/latest.json은 전체 실행 파일 명세이고 updates/files는 내용의 SHA-256 이름입니다. 기존 공개 객체와 Git 트리는 보존하고 새 객체만 추가합니다. 개인 저장·인증·프로필·개인 QA·프롬프트 원문은 게시하지 않습니다.
