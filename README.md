# 촉한전기

현재 버전: **v0.74.9** · 1~7막, 1~56장 완결

[웹에서 실행](https://syrano15.github.io/shu-tactics-updates/)

장별 군세의 표시 색과 명칭을 정리하고 원소군·남만군을 구분합니다. 18장 적 증원은 최대1회(기본28+증원5=최대33)로 제한하며 기존 저장의 이미 등장한 부대·완료·보상은 보존합니다. 원천 지도·이미지와 요청 밖 규칙·RNG는 바꾸지 않습니다.

군세 표시는 실제 소속에 맞게 구분하고 원래 규칙 데이터와 원화는 보존합니다. 18장 증원은 최대1회로 제한하며 기존 저장의 기등장·완료·보상은 유지합니다.

updates/latest.json은 전체 실행 파일 명세이고 updates/files는 내용의 SHA-256 이름입니다. 기존 공개 객체와 Git 트리는 보존하고 새 객체만 추가합니다. 개인 저장·인증·프로필·개인 QA·프롬프트 원문은 게시하지 않습니다.
