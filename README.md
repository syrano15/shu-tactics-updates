# 촉한전기 업데이트

현재 버전: **v0.60.2**

기존 PC 타이틀에서 업데이트 확인 → 업데이트 적용 → 이어 하기를 사용합니다. 현재 1~6막 1~45장, Lv99 성장입니다.

- 게임 저장을 더 큰 저장 공간에 보관합니다. 기존 자동·수동·장별 기록·완료·백업은 원문을 보존해 옮기며, 육성·장비·강화·자금·진행·정산과 저장 파일 형식을 유지합니다.
- 저장 완료를 확인한 뒤 완료 표시를 보여 줍니다. 이행이나 쓰기에 실패하면 기존 기록을 보존하고 파일 내보내기를 안내합니다.
- PC판과 웹판은 각자의 기기와 주소에 저장합니다. 이번 버전은 클라우드 연동이나 7막 추가를 포함하지 않습니다. 다른 기기·브라우저·PC판으로 옮길 때는 JSON 파일 내보내기/가져오기를 사용합니다.

v0.60.1의 백마 증원 한 번·적 책사의 반복 혼란/위보 보호·백마 흙둑길, 기존 1~6막과 Lv30 선택 정신기·Lv50 고유기·강화15를 유지합니다. 7막 이후 전투는 미구현입니다.

검수는 기존 저장의 사본, 실제 엔진/저장 API, 실제 화면과 격리 PC 실행을 구분합니다. 개인 프로필 원본은 건드리지 않습니다. 개인 저장 원문·검수 프로필·개발 문서·원천 아트·인증 정보는 공개하지 않습니다.

`updates/latest.json`의 실행 자료는 크기·해시·호환성을 검증하고 변경 파일만 내려받습니다. 이전 공개 자료와 실행기의 보호 검증을 보존합니다.
