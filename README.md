# 촉한전기

현재 버전: **v0.71.0** · 1~7막, 1~56장 완결

[웹에서 실행](https://syrano15.github.io/shu-tactics-updates/)

3~7막의 일반병·통상 정예 병력을 전면 점검해 급격한 증가를 완화합니다. 3막은 일반병 6,000~6,800, 정예 8,000~8,800으로 조정하고, 이후 막도 통상 잡병은 병력 상한을 제한합니다. 6~7막 일부 정예는 호표기·철갑기병·저격병·방패병·장창병으로 구분하며 이동·사거리·공방·상성에 맞는 공략을 제공합니다.
2막 이후 양군 책사의 단일 화공 위력을 35%, 범위·화공 필살기를 25% 높입니다. 1막, 비, SP, 지력 성장과 영창을 유지합니다. 기존 활성 전투는 전체 검증 뒤 남은 병력 비율을 보존해 한 번 조정하고, 장수 육성·장비·자금·진행·사망·완료·보상 기록은 보존합니다.
수동 패치의 96MiB 안전한도는 유지하고 초과 파일은 만들지 않습니다. 전체 PC 실행본과 온라인 개별 파일 갱신을 제공합니다.

기존 장별 완료와 육성은 보존합니다. 다른 진행을 합치지 않으며 클라우드 충돌에서는 양쪽 원본을 보관하고 선택합니다. 현재 진행만 연동하고 수동 저장 56칸·장 시작·클리어·완료 기록은 각 기기에 남습니다.

updates/latest.json은 검증된 전체 실행 파일 목록이며 updates/files는 SHA-256 이름의 내용입니다. 새 버전에서 필요한 파일만 추가하며 이전 공개 파일은 삭제하거나 덮어쓰지 않습니다. 개인 저장·인증정보·검수 프로필·개발용 프롬프트·원천 아트는 게시하지 않습니다.
