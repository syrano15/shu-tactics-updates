# 촉한전기

현재 버전: **v0.72.1** · 1~7막, 1~56장 완결

[웹에서 실행](https://syrano15.github.io/shu-tactics-updates/)

자연스러운 2D 회화풍 수면과 해안·모서리·다리/나루·강하 피난선 접안 표현을 수면 전장 21개에 맞춰 미리 생성합니다. 기존 지형·통행·좌표·출구·보호·목표/승패 조건은 그대로 유지합니다. 원본 아트와 기존 배치도 보존합니다.
전맵 배경은 전장당 공유 표시층 한 벌로 유지하며, 선택 장수·명령·범위 갱신 때 칸마다 전맵 SVG 필터를 반복 적용하지 않습니다. 실제 지형 서명이 맞는 그림만 사용하고 서명이 다르거나 그림을 읽지 못하면 기존 대체 표시를 유지합니다.
한글 가변 글꼴은 전체 문자와 윤곽·가변축·이름을 유지하는 WOFF2로 제공하고 원본 TTF와 라이선스도 보존합니다. 초기 모듈 읽기를 겹치고 효과음 준비 시점을 정리하여 시작 시 불필요한 일괄 요청을 줄입니다. 효과음 자료·음량 선호·실제 전투 발동 경로는 유지합니다.
평상시 빈 땅 우클릭에서 전장 메뉴와 전투 목표를 열 수 있도록 입력을 정리합니다. 이동/대상 지정과 지도 끌기는 기존 우선순위를 유지하며, 선택 장수 명령과 명시적 확정·취소를 보존합니다.
1~7막 56장·Lv99, 기존 육성·장비·자금·진행·완료·보상·저장 형식과 치명타 계산·저장된 선호를 보존합니다. 적 정신기·SP·AI·HP·밸런스·대사·승인 초상은 변경하지 않습니다. PC와 휴대전화는 같은 웹 게임의 기능·데이터·명령을 사용합니다.
개인 저장·인증정보·검수 프로필·원천 아트·개발용 생성 프롬프트는 공개하지 않습니다. 자동/정적 검사와 실제 사용자 플레이·체감·최종 미술 승인은 구분합니다. 수동 패치는 기존 96MiB 안전한도를 유지하며, 초과 시 생성하지 않고 전체 PC 실행본과 온라인 개별 파일 갱신을 제공합니다.

기존 장별 완료와 육성은 보존합니다. 다른 진행을 합치지 않으며 클라우드 충돌에서는 양쪽 원본을 보관하고 선택합니다. 현재 진행만 연동하고 수동 저장 56칸·장 시작·클리어·완료 기록은 각 기기에 남습니다.

updates/latest.json은 검증된 전체 실행 파일 목록이며 updates/files는 SHA-256 이름의 내용입니다. 새 버전에서 필요한 파일만 추가하며 이전 공개 파일은 삭제하거나 덮어쓰지 않습니다. 개인 저장·인증정보·검수 프로필·개발용 프롬프트·원천 아트는 게시하지 않습니다.
